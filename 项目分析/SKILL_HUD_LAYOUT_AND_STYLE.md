# 战斗技能栏布局与中央怒气外观

当前稿按用户新的武当技能栏参考返工：技能横条紧凑、灰黑半透明内底、蓝白细边；中央是带宽倒角和窄暗槽的暗灰硬质圆盘，盘内有向上五剑扇形浮雕，下方保留 R，满怒后才出现青蓝细环。复用本项目背包 Common1 图集与既有 LiberationSans SDF，并为中央硬框绘制少量专用透明几何纹理，没有复制参考游戏图片。

## 当前布局

- 沿用原 UIRoot 的 1920×1080 设计基准及按宽度缩放，整个技能栏位于屏幕下沿。
- 左侧 Q/E/F/1/2 五槽，中央原 R，右侧 3/4/5/6 加一纯视觉空格。十个固定快捷键、服务端 BindKey 与已学技能填槽方式保持。
- 下方长条为原 HP/MP，继续保留。中央左真气、右气力紧贴盘身，嵌入外框与内盘之间的窄凹槽，与下方长条分别展示；此前悬浮外弧稿已被本轮覆盖。HUD 头像、昵称、职业和所有资源文字数值已去掉，窗口不再发起头像资源请求。外部 RoleCurrentViewData、RoleInfoCtrl 契约保持。
- 空格没有技能组件、事件或请求。未学习的固定快捷槽沿用原 Clear 行为，不生成药品、技能或额外快捷键。

## 暗态与满怒态

实际检索客户端角色/技能数据、服务端协议/Common/GameServer 后，没有独立怒气字段或积累/消耗链。用户明确本轮只做 UI，怒气玩法以后接入。当前正式没有怒气来源调用，默认始终为未满暗态。

窗口提供 `UpdateRage(int currentRage, int maxRage)`：只有上限大于零、当前值达到上限时才判为满怒；非正上限视为未接入。`SkillSlotWidget.SetRageFull(bool)` 仅切换中央可选 ReadyVisual 和已加载技能图标，普通槽未绑定该节点，继续照常显示图标。窗口缓存一个满态值供异步中央槽创建后同步，晚到图标按节点的当前状态决定是否显示。

未满中央以少数清楚的硬轮廓、宽灰阶倒角面和窄暗槽体现厚度，不使用等距多条同心亮线或默认泛光。154 设计单位外壳使用 `HudCoreHousing.png`，126 单位内盘使用 `HudCoreDisc.png`，104 单位五剑浮雕使用 `HudSwordFan.png`，均由几何轮廓原创绘制。左上倒角略亮、右下压暗，盘面轻微上亮下暗；原生 uGUI Mask 保持圆裁剪。满态细环仍使用 Common1 白圆，所有青蓝怒气亮环归 ReadyVisual 且默认失活；技能图标未满只加载不显示，满怒时显示。

接口不累积或消耗怒气，不发包、不计时充能，不读取 CD/MP 推断满怒，也不新增施法门禁。R 仍是原快捷技能，继续按现有输入和 CD 逻辑释放；怒气玩法接入以后再定义具体规则。

## 真气与气力弧条

用户明确中央圆盘两侧另有真气和气力，底部 HP/MP 不变；最新要求初始化为满真气、满气力，因此两条预制体填充值均为三分之一整圆，即完整120度资源槽。当前没有玩法调用方，窗口初始化不覆盖这两个序列化值；中央怒气仍默认未满暗态。

2026-10-12 用户报告气力未满，实际根因在当前 `LYF_MMO/Assets/GM_Game/Scenes/New Scene.unity` 的 UIRoot 实例：单独把气力 Image 的 `m_FillAmount` 覆盖为0，真气继续继承预制体满值。最小修复仅删除该四行覆盖，让两条均继承预制体；其他场景内容、预制体和源码保持。正式预制体原样初始化的 Unity 原生图确认双满且怒气暗，场景修复前后有效值用真实覆盖清单与继承关系核对；隔离场景变体预览未成功，不宣称已渲染正式场景。

后续接入数据时，`RoleCurrInfoWindow.UpdateTrueQi(int currentTrueQi, int maxTrueQi)` 只更新左弧，`UpdateStamina(int currentStamina, int maxStamina)` 只更新右弧。调用接口时上限非正数仍显示空条，当前值为负时钳为零、超过上限钳为满。初始满条只决定创建界面的外观，不改这两接口的数值语义。两个数值各自独立，不读取 MP、移动状态或怒气替代，不新增玩法规则。

弧条在 UIRoot 的原 HUD 子树直接配置，以 uGUI Image Radial360 展示各三分之一圆；显示直径缩至 144 单位，位于外壳半径 68–73 单位的暗凹槽内。接口仍先把点数钳成 0–1 比例，再乘三分之一圆范围；左青蓝、右浅金，初始均填满，空余部分使用灰暗轨，无文字数值。弧条和新增框体 Graphic 不截获世界点击，与中央 R 的原冷却数字及满怒 ReadyVisual 独立，也不改变原技能或 HP/MP 的状态。

专用透明细环 `Assets/GM_Game/UISprites/Icon/HudResourceArc.png` 从本项目背包 Common1 白圆切片21300174派生，原细环素材为616像素，前轮显示直径154设计单位，本轮显示144单位，线宽随等比缩放。它只解决旧图集小环放大后过厚模糊的问题，使用现有 uGUI 组件，不新增绘图脚本、管理层或第三方素材。生成来源与首厚弧失败证据保存在前轮 `_temp/skill-hud-qi-stamina-20261011/develop/`。
