# 技能根运动远端不同步定位

日期：2026-10-13。范围仅用户所述“本地施法位移、另一端原地播动画、技能后再移动”。

## 事实链

- `MArtSkill.TriggerAnim` 会对当前模型的 `SkillRootMotionCollector` 绑定技能；`OwnsRootMotion` 没有限制必须是本地玩家。远端能正常取得技能动画及根窗口。
- `SkillRootMotionCollector.OnAnimatorMove` 从原生 `Animator.deltaPosition` 采集水平差量，`ConsumeDelta` 才会清掉并交付这些差量。
- 本地 `MMoveComponent.PlayerUpdate` 已消费根运动；修前 `Update` 远端分支仅执行 `LagSyncUpdate` 和程序位移组件的 `ConsumeDelta`，没有读取根采集器。
- 普通移动的 `LagSyncUpdate` 受 `CurrentState.IsActiveMovable` 控制；不可方向移动的技能期间直接返回。位置上报仍能把本地技能实际坐标传来，因此远端只能在技能退出后追赶缓存目标，吻合用户表现。

## RO 对照与本项目必要适配

RO `Components/Common/MMoveComponent.cs` 的 `LagSyncUpdate` 同样受动作可移动性限制。其 `Skill/SkillLogic/MArtSkill.cs` 经 `MEvent_Displacement` 派发技能程序位移，技能位移与普通影子跟随分工独立。本项目额外使用真实 Animator 根采集器，因此应让远端也消费现有根差量，不能靠放开普通移动权限代替技能运动。

## 最小修复

仅修改 `LYF_MMO/Assets/GM_Game/Scripts/SceneEntity/Component/MMoveComponent.cs` 的 `Update(int)` 远端分支：先合并动画根运动与可选程序位移，非零时只提交一次碰撞移动；没有技能差量时保留原影子跟随。这样没有程序位移组件的角色仍可消费根运动，允许方向移动的技能也不会在同一帧叠加影子追赶。

技能移动后沿现有影子字段重新计算实际位置到缓存目标的剩余方向和距离，并清零该段经过时间。否则缓存的施法前方向和距离会在技能结束后继续被累计，出现二次前移。精确抵达目标时恢复 `keep_moving`，避免位置停止但保留移动动画。碰撞时依实际落点计算剩余距离，原程序位移停止行为保留。

没有新增协议、状态字段、等待、队列、重试或管理层；本地输入、跳跃、技能生命周期、配置表与资源保持。

## 验证及边界

开发 280 源 Rebuild 零错误、38 既有警告；独立280源零错误、39既有警告。独立生产方法抽取修前15项复现/回归、末稿19项通过，覆盖根差量消费、空程序组件、根与程序合并、普通跟随、可移动技能不双叠、落后目标在非零根帧不回拉、结束后的剩余路程、碰撞裁剪与移动态收束；方法外及七保护文件保持。

原生隔离夹具使用正式远端预制体、滑步动画、生产根采集器、生产移动方法及 CharacterController；反射仅装配测试施法、独立动画信息和影子目标缓存。该夹具不执行真实网络入口，不能代替双账号正式联机。首次运行未取得原生根差量；第二次针对编辑器预览回调补手动派发生产采集，已取得40帧约5米根运动，但起点装配误差仍失败。两次结果保留，只修临时起点后交主执行，不为夹具失败增加业务校验。

第三次原生末稿验收通过：40帧正式Humanoid采集4.999855米、实际移动4.999854米，误差`9.536743E-07`米；差量已清空、抵达目标后停止移动，退出技能后没有追加距离或移动动画状态。编辑器非Play显式派发生产`OnAnimatorMove`，缓存目标手动装配的边界保持；正式双客户端网络时延及画面仍待现场回归。

该次行为验证后发生一条Edit预览清理错误，来源为测试夹具先执行实体Play回收触发`Object.Destroy`。仅调整临时清理顺序为先立即销毁原生测试模型、再回收实体，保留原结果与错误，不将此测试清理问题归因于技能业务，也不修改正式回收逻辑。
