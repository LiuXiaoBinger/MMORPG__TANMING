# Gene 基因运行模块与配置说明

本项目统一使用 Gene／基因称呼增益和减益效果。本次范围为基因表、通用运行模块及实体生命周期接入；具体技能施加、战斗资源结算、客户端网络同步未接入。

## 配置入口与属性单位

源表：`Luaban/MiniTemplate/Datas/#Gene.xlsx`。运行数据：`LYF_Server/Network/LubanManage/Tb/tbgene.bytes`；类型由 Luban 生成到 `LYF_Server/Network/LubanManage/Codes/Gene.cs`。

保留原有 1～23 号属性定义及原行数值，新增 46 条，共 69 条。原 `buffTime` 字段改为 `GeneTime`，因此必须同时更新生成代码、二进制表及客户端 `Network.dll`，不能混用旧表和新解析器。

| 字段 | 配置规则 |
|---|---|
| Id / EffectDesc | 唯一编号及中文效果说明。 |
| Scenario | 0 全局，1 副本，2 PvP。全局配置在三类环境均可生效。 |
| ValueType / Value | 0 固定值，1 相对基础值百分数；10 表示 10%。负数表示削弱。Value 是每层数值。 |
| AttachGeneId0～4 | 组合基因最多引用五个叶子配置，0 留空。不支持组合递归嵌套。 |
| IsStack / MaxStack | 同编号、同来源：IsStack=0 允许叠加，MaxStack=0 不限层；IsStack=1 只刷新寿命。不同来源独立。 |
| GeneTime | 持续秒数，0 常驻；运行时剩余时间为毫秒，-1 表示常驻。 |
| EffectType | 0 属性，1 持续伤害，2 持续治疗，3 持续回蓝，4 状态，5 组合。 |
| AttributeId | 属性效果使用 `GeneAttributeType` 编号；其他效果填 0。 |
| Interval | 周期毫秒数；持续伤害、治疗、回蓝必须大于 0。第一次触发在第一个完整周期结束时。 |
| State | 位标记：1 眩晕、2 定身、4 沉默、8 霸体，可相加。 |

1～23 号与现有外功、内功属性保持一致。命中、暴击、格挡是面板点数，不是概率。暴击伤害 151 表示 151%，固定修正 +10 表示加 10 个百分点。23 号“气”保留为原表的基础属性，不代指法力或轻功气力；当前角色协议没有对应字段，调用方应自行提供基础值。

新增属性编号：24 移速（沿用基础速度单位）；25 承伤倍率百分数；26 受疗倍率百分数。后两者通常以 100 为基础值，目前只提供计算结果，不自动改写伤害、治疗或移动逻辑。

## 运行行为与调用入口

客户端 `MEntity.Gene.Runtime`，服务端 `GeneComponent.Runtime`。服务器通过 `GameServer.csproj` 链接客户端目录中的七份无 Unity 依赖的 Gene 源码，两端使用同一套算法，不另建管理器。

- `AddGene(geneId, sourceId, value)`：创建或叠加同来源实例并刷新寿命；单效果允许覆盖数值，组合使用叶子表值。重复施加保留已经累计的周期进度。
- `RemoveGene(geneId, sourceId)`：只移除指定来源，同时移除其组合叶子。
- `CalculateAttribute(attribute, baseValue)`：基础值 ×（1 + 所有百分比修正之和 / 100）+ 所有固定修正之和，每项均计入层数。不写回基础值，避免到期时反算误差。
- `Update(deltaMilliseconds)`：返回本帧周期结果列表，跨越多个周期时补齐，但只结算真实存续时间。恰好在到期时刻完成的周期会触发。组件随后逐条发送 `Pulse` 事件。
- `GenePulse.ResolveAmount(maxHp, maxMp)`：固定点数直接取整；百分比伤害／治疗以目标生命上限为基数，回蓝以目标法力上限为基数，向零取整。宿主负责消费结果、应用承伤／受疗修正与资源上下限。
- `GetStates()` / `CanMove` / `CanCast`：提供控制判定。霸体屏蔽眩晕和定身，不屏蔽沉默；霸体期间已有控制仍计时，霸体结束后未到期的控制重新可见。
- `SetScenario(scenario)`：切换场景类型并移除不适用的父实例；组合叶子也按其场景过滤效果。
- `Clear()`：销毁或回收时清空。组件回收同时解绑周期订阅。

组合父项拥有层数、剩余时间和来源，子项只提供效果类型与参数。组合叶子的 GeneTime、IsStack、MaxStack 不单独执行；单独添加同一叶子编号仍是独立实例。

参考 RO 的 `rogamelibs/entity/component/buff_component.cpp`、`rogamelibs/entity/buff/buff.h` 中“实体组件持有实例、实例持有效果”、施加、刷新、周期推进与移除职责；只适配本项目需要的属性、周期、状态和五槽组合，未移植 RO 的专有技能、Lua 或网络体系。参考根目录为 `F:/UnityPro/ro/Ro_cs422nb`。
