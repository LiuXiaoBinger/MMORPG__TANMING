## 四、逐条目明细

### 类别 A：确认死代码（无任何调用者）

#### A1. LoginModle 末尾背包迁移私有方法集群
- 文件：`LYF_Server/CenterServer/DB/Modle/LoginModle.cs`
- 行号范围：521–585
- 代码类型：私有静态/实例方法（4 个）
- 代码片段摘要：
  - `private static KnapsackType[] GetPersistedKnapsackTypes()`（521）
  - `private static int GetLegacyFallback(List<RoleKnapsackTable> rows)`（533）
  - `private static int GetMigratedGridCount(RoleKnapsackTable row, int legacyFallback)`（548）
  - `private void EnsureMissingKnapsackRows(int roleId, List<RoleKnapsackTable> rows, int legacyFallback)`（558）
- 判定依据：Grep 搜索 `EnsureMissingKnapsackRows|GetLegacyFallback|GetMigratedGridCount|GetPersistedKnapsackTypes` 全目录。在 LoginModle 内，仅 EnsureMissingKnapsackRows 内部 562 行调用 GetPersistedKnapsackTypes；而 EnsureMissingKnapsackRows 本身在 LoginModle 内**无任何调用者**。其余三方法在 LoginModle 内也无调用点。CentRoleModel 拥有功能等价且被实际调用的同名方法（CentRoleModel.cs 386/398/413/424，由 204/205/284/294 行调用）。
- 处理建议：**可删除**。属从 CentRoleModel 复制后未接线的残留私有副本。本次已在其上方加注释说明，未删除。
