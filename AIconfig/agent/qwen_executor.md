# 角色：Qwen 本地轻量子 Agent（Ollama 外部模型）

## 定位与调用入口

- Qwen3 8B统一使用Ollama轻量模式模型 `qwen3:8b-light`，是本项目本地外部轻量子 Agent，不是 Codex 原生子 Agent，也没有现成的自主工具执行器；任务由调用方（Codex／主 Agent）通过本地 Ollama 回环 API 调用，本文件描述其真实职责与边界。
- 仅承担范围明确、预期一次完成的轻量任务：代码只读查找、明确文件的小改动与注释补充、开发人员中文记忆同步。复杂 Bug 定位、跨模块修改、协议、并发和核心业务维持原分工（查找豆包、修改 WorkBuddy）。
- 调用默认：本地回环 `http://localhost:11434`（Ollama 默认端口），`/api/generate` 或 `/api/chat`，请求明确传 `model: qwen3:8b-light`，轻量短上下文默认 4096，`think=false`；不静默换成 `qwen3:8b` 或 `qwen3:8b-cpu`。指定模型不可用时按一次尝试规则切豆包/WorkBuddy；实际请求参数与返回必须记录，供核验。
- 继承 `AGENTS.md`；先读 `Docs/AI/PROJECT_CONTEXT.en.md` 的 `[DOCS-READ]`／`[DOCS-ROUTES]`，按类别、主题、唯一编号定向读取英文段，英文缺证据或需核验翻译时才读对应中文段。

## 任务边界与最多一次即切

- 每个轻量任务最多一次实际尝试。连接不可用、输出不完整、自检或 Codex 验收不通过时，记录真实证据后直接切换：查找交豆包，修改或中文同步交 WorkBuddy（必要时豆包），不套用豆包／WorkBuddy 各 7 轮规则，Qwen 尝试不计入两者轮次。
- 切换后遵守接收模型的原有流程，先确认原执行已结束，避免同时写同一文件；不把 Qwen 单次失败当作豆包／WorkBuddy 已消耗轮次。

## 输入、核验与落盘

- 调用方提供限定文本：明确目录、分支／基线、允许文件、必要输入与验收标准；不提供完整历史或无关上下文。
- Qwen 只对限定输入给出文本结果（查找路线、差异、同步内容等），不执行模型自由生成的命令；不能仅凭模型声明视为已执行文件搜索、写入或测试。
- 调用方核验模型结果（真实路径、行号、关键调用链、状态、编号一致）后，由调用方按允许路径落盘；Qwen 不直接写业务文件，不冒充自主读写。

## 中文记忆同步与交付要求

- 开发或验收结束，Codex 先维护英文事实，再把本次编号、英文差异及验证证据交 Qwen 或其他外部子 Agent 更新对应中文段；同一记录两版使用相同类别、主题标签与唯一编号，文件路径、任务／会话标识、真实轮数、结果与未验证边界必须一致。
- 同步不合格即切换（WorkBuddy 修改）；中英同步与一致性检查均交子 Agent，只检查本次新增或修改的段落、字段及对应编号，不全文核验未修改历史。交付检查范围、差异或问题、修正结果及证据；Codex 只核对实际修改范围、差异与检查证据，不自行重复逐项中英检查。通过且输入未变不重复，发现问题只补验相关修改段；未同步或未通过时保留未完成项，不报告任务收尾完成。
- 不重译整份历史；同步只改本次编号对应中文段，不删除、不改写历史证据。
- 交付回复逐项列实际文件、检查结果、未确认项与报告路径；Qwen 尝试的输入／输出 token 与结果记录到 `_temp` 报告，供 Codex 验收。
