## [FILES][角色][ROLE-FACE-MATERIAL-20261025] Character face/material "washed out" fix, 2026-10-25

- User reported the character face looks weird in-scene and "ugly" compared with other projects. Ruled out a material-source mismatch first: Unity shows all four UTS renderers of `Role_JX.prefab` use `materials/P03_*.mat`, no code swaps role materials at runtime, and the role is not loaded from AssetBundles — so the editor view equals the in-game view.
- Root cause 1 (definite bug): `P03_Skin_Normal.png` was imported as Default (`textureType: 0`, sRGB on) → runtime DXT1. On desktop `UnpackNormal` reads A/G (DXT5nm), so normal data was wrong; the sibling `P03_cloth_A_normal` was already NormalMap/DXT5. Fixed to NormalMap with sRGB off.
- Root cause 2 (main cause of the washed-out look): `UCTS_ShadingGradeMap.cginc:190/192` adds `_HighColor_Tex × _HighColor` straight onto base, while `_Set_HighColorMask` is null (default white) on all seven materials — so each material got "its own colour × factor" added (skin 0.15, hair 0.27, cloth 0.35, eye 0.69, brows 0.53, cheek 0.28, metal 0.20). All seven `_HighColor` values are now zeroed.
- Root cause 3 (flat look): `P03_skin` `_1st/_2nd_ShadeColor` were nearly white (0.943/0.906), leaving no shading steps. Now (0.886,0.784,0.780) / (0.749,0.596,0.612).
- Only these eight asset files plus a changelog changed; no code, shader, scene or prefab edits. Manifest, four-way comparison and rollback: `项目修改日志/2026-10-25-角色面部材质发白修复_CHANGELOG.md`.
