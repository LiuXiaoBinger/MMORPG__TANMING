## 设计思路

- 豆包按外部开发子 Agent 调度，GPT 保持主控、审查与验收；不把网页执行者伪称为 Codex 原生子 Agent。
- 每次派发和返工都先读实际页面，确认 LYFMMORGP 项目与“工作任务 云电脑”，已正确时确认即可；新任务在项目内建立，返工沿原任务。
- 明确云电脑与本地文件没有已验证的自动同步。以真实补丁或产物回收，由本地开发子 Agent 核基线后落盘，主 Agent 组织验收，再按原分支规则提交推送。
