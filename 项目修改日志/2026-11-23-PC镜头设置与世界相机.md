## 玩家操作与设计依据

参考录屏 `D:/录屏/wyclx64 2026-11-23 21-20-15-996.mp4` 的镜头分页。录屏展示五种模式、每种模式的说明和十二项勾选。四个固定预设展示各自的功能组合，自定义可以逐项勾选。桌面端沿用右键拖动和滚轮，采用中键复位；可单独开启双击地面转向。触屏手势按开发者要求延期。

| 模式 | 本项目的镜头表现 |
| --- | --- |
| 智能 3D | 首次启动默认选中。支持自由俯仰和环绕，普通战斗和首领战分别扩大观察范围。 |
| 定制 2.5D | 切入时记录当前 FreeLook 俯角，之后可水平环绕和缩放。换场景、重启后沿用该角度。 |
| 普通 3D | 普通战斗保留玩家设定的距离，首领战可自动拉高。 |
| 默认 2.5D | 使用归一化竖轴 0.72 的固定俯角，接受水平拖动与滚轮输入。 |
| 自定义 | 独立保存十二项开关，切到固定预设再切回来可继续原组合。 |

主城与魔神塔共用的场景 FreeLook 原先使用 `SimpleFollowWithWorldUp`，Cinemachine 2.10.7 会在更新中清空水平轴。世界相机改用 `WorldSpace` 保存实际航向，复用已有跟随点、注视点与场景避障配置。右键拖动由按下位置决定归属，窗口内开始的操作和滚轮交给 UI。战斗缩放在手动距离上临时叠加，连续滚动从当前轨道平滑过渡。攻击、命中或受击后保留三秒构图，持续交战时刷新，结束后恢复玩家的观察距离。中键、双击地面、寻路和首领构图都只改变镜头；首领锁定在设置中可独立开启。

对照原 RO `config/Table/CSV/EntityTable.csv` 的 `UnitTypeLevel=2`，为魔神塔 5501、5502、5503 和贝森 9751、9801 保留首领身份。副本沿用原实体生成与伤害处理。技能特殊效果开关控制技能单独配置的镜头重音；基础起手、命中的短反馈沿用原入口。轻功按技能主表 `Type=4` 识别，当角色下方有 `Geometry` 地形时显示地面圆环。

## 验证

- Unity `2023.2.20f1c1` 隔离 Play Mode 使用编译后的实际游戏代码、设置预制体、Cinemachine、Input System 和项目地面提示资源。预制体测试副本将 SettingPanel 的原脚本引用映射到同一类的编译程序集。正式场景和预制体均未挂测试组件。
- 45 项主检查通过，覆盖五套勾选结果、禁用态点击、自定义保留、UI 遮挡、横纵轴独立控制、两种 2.5D、复位、地面双击、首领/普通战斗、技能重音和落点资源。10 项补充检查测到 FreeLook 最终位置变化、D 键和寻路独立转向，以及实际技能表 10090 的轻功提示。另启 Unity 后的 3 项设置回读通过。
- 定制测试俯角 0.63 锁定。Windows 单个 120 单位滚轮刻度将目标高度从 12 米调到 10 米。普通战斗中层半径从 8.4 米增至 10.416 米，退出后回到 8.4 米。参考视频仅展示设置面板，这些角度、距离和计时是本项目采用的参数。
- 工作区全程序集直接编译在修改前后均有完全相同的 4 条报错，分别是宝石接口和护盾粒子局部变量。仅在隔离编译清单把 `RoItemComponent.cs`、`MjsBarrierVisual.cs` 换为 Git 版本后，客户端程序集编译通过。独立抽取功能分支基线 `027bd35` 及任务候选树，二者都在 `MainCtrl.cs` 出现相同的 11 条原有语法错误。未修改上述无关源文件。
