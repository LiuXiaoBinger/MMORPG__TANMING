# RO 摆摊询价与撤单

任务编号 `STALL-SELLER-20261125`，功能分支 `codex/feature-development`。

## 范围及参考

RO 的客户端 `ModuleMgr/StallMgr.lua` 和交易服 `stall/stall_manager.cpp`、`protocol/stall/rpcc2j_stallgetpreselliteminfo.cpp`、`rpcc2j_stallsellitemcancel.cpp` 提供询价、卖家身份、撤单请求及职责参考。项目延用 `StallManager`、`StallGetPreSellItemInfo`、`StallSellItemCancelArg/Res`、`SendStallSellItemCancelReq` 等名称。本项目参考价使用本区有效挂牌的最低单价。RO 的基准价和表内上下限没有引入。中心服只更新属于当前卖家的在售行，撤单不修改库存、持有成本和物品快照。完整架构见 `项目分析/玩家交易商城设计-2026-11-25.md`。

## 业务文件

- `LYF_Server/TradeServer/StallMarket.cs`。原摆摊索引文件移至 StallManager.cs。
- `LYF_Server/TradeServer/StallManager.cs`。移入 RO 同名管理器，汇总有效挂牌、受理撤单并在权威回执后更新卖家和公共索引。
- `LYF_Server/TradeServer/TradeServerApp.cs`。注册撤单入口并装配 StallManager。
- `LYF_Server/TradeServer/TradeServer.csproj`。编译新的管理器文件名。
- `LYF_Server/CenterServer/CenterApp.cs`。注册中心服撤单提交协议。
- `LYF_Server/CenterServer/Ctrl/StallLoadCtrl.cs`。原子核对区、市场、卖家、状态、数量和截止时间；仅改变状态、关闭时间和版本。
- `LYF_Server/GateServer/GateServerApp.cs`。注册卖家撤单及既有查询入口。
- `LYF_Server/GateServer/Ctrl/GateStallCtrl.cs`。旧模式返回与原挂牌对应的不可用提示。
- `LYF_Server/GateServer/RealmGameLink.cs`。从玩家实际会话确定区、角色和宿主，并转发撤单及回执。
- `LYF_Server/Network/Proto/StallRead.cs`。由 protoc 重新生成的 C# 消息类型及描述。
- `LYF_Server/Network/Socket/com/StallCode.cs`。分配撤单请求、内部提交和玩家回执的命令号。
- `LYF_Server/ProtoBuf/proto/StallRead.proto`。增加出售询价视图、撤单参数和内网回执。
- `LYF_MMO/Assets/LYF_Game/Plugins/Net/Network.dll`。Unity 客户端使用的新协议库，已比对运行时协议描述。
- `LYF_MMO/Assets/LYF_Game/Prefabs/UIPrefabs/TradeMarketWindow.prefab`。保存三个可独立点选的寄存行和参数绑定。
- `LYF_MMO/Assets/LYF_Game/Scripts/UI/Main/Window/TradeMarketWindow.cs`。出售页询价、寄存行选择、撤单回执与刷新。
- `LYF_MMO/Assets/LYF_Game/Scripts/UI/Main/Window/Widget/TradeMarketDialog.cs`。显示参考价和草稿合计，保留玩家拟填单价。
- `LYF_MMO/Assets/LYF_Game/Scripts/controller/UIController/MainCtrl.cs`。发送撤单请求并将业务回执交给当前窗口。

## 验收与边界

- 单区、双 GS、两名真实 TCP 测试角色和独立 MySQL 库。不同角色、其他区、其他市场、已到期和零余量的撤单均被拒绝；同一挂牌重复撤单只递增一次版本。两条线查询的剩余数量和最低价同步变化。重启 TradeServer 后挂单状态、余量和价格保持一致。测试挂单由隔离库预置。
- 服务端和工作区 Unity 客户端编译通过；单独校验双方消息描述一致。本机 Unity 隔离 Play Mode 完成 12 项检查，实际点击两个不同行分别得到正确的挂牌号，已撤行不可再操作。询价切品时的迟到回包未覆盖当前商品，草稿价格在收到参考价后保持玩家输入值。
- 证据位于 `_temp/stall-seller-20261125/accept.txt`、`ui-checks.txt`、`wire-check.txt`、`我的摊位撤单.png`、`出售询价.png` 和 `token-summary.json`（以上短文件名均在同目录）。服务端网络验收和 Unity 界面验收分开执行，未运行两个完整 Unity 客户端、真机或 Player。新物品寄售、买家扣款交货、取回余货和领取收益仍待开发。
