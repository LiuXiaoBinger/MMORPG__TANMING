# 玩家双向进出视野与主角纠位后继续寻路

2026-11-23 · `AOI-NAV-CORRECTION-20261123` · `codex/feature-development`

同图同实例的两名玩家自然走到相距 100 米以内时，双方各收到对方的当前资料。超过 100 米时，双方移除对方。主角收到 `11182` 后先到达服务器指定坐标，如果正在自动寻路，就从这个落点继续追原目标。此前确定的 1.2 秒位置上报超时与移动节拍沿用原设置。

## 验收

GameServer 和 Unity 客户端业务程序集编译通过。服务端回环从 `ROMoveComponent.OnMoveStart` 驱动两个角色，并分别加入不同地图、不同实例的观察者，按收件会话、角色 ID 和协议号核对实际下发。

| 步骤 | 实测下行 |
| --- | --- |
| A 相对 B 从 102 米走到 99 米 | 双方各收一条 `11100`，B 随后收到 A 的 `11181`。B 原本零血，A 收到的 B 资料保留零血。 |
| 99→100 米 | B 只收到 `11181`。 |
| 100→101 米 | 双方各收一条 `11213`，每条指向接收者应移除的对方。 |
| 101→103 米 | 双方均无下行。 |
| 由 B 移动，使双方恰好相距 100 米 | 双方各收到一次出现，A 收到 B 的移动。 |
| A 在范围内移动 | B 只收到 A 的移动。 |
| B 再次走出范围 | 双方各收到一次离开。其他地图、实例的观察者在以上七步均未收到消息。 |

独立 Unity 2023.2.20f1c1 批处理加载当前客户端程序集，使用实际消息处理器、实体池、模型绑定、导航和技能预测。连续两条移动到达时，模型采用第二条的坐标、128 度朝向与第二段跳跃。加载中离场后，晚到移动无法重建实体，再入场使用新坐标，零血进入死亡状态。主角验证了手动纠位、忽略他人的纠位，以及向原坐标重新寻路。在中央为 4×4 米不可走区域的网格上，纠位后沿新路线追同一只怪，25 个模拟移动步进入射程，技能 `10010` 的本地 UUID 只增加一次，重复纠位后仍是同一次预测。

本次单次施法以本地 UUID 和技能核心的预测记录为准。隔离工程未连接技能服务器，也未加载角色技能动画资源。两台完整客户端经真实网关的弱网观感、技能最终结算和技能动画尚未联测。
