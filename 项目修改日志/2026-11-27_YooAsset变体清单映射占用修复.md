# YooAsset 着色器变体清单映射占用修复

任务编号 `YOO-SHADER-MANIFEST-20261127`。2026-11-27 在 `codex/feature-development` 修复项目内的 YooAsset 1.5.7 编辑器包。用户授权从当前已保存的变体集合重新生成正式 JSON，并批准本任务记录及新增段落的双语核对。

## 现场和取舍

Unity 在 `ShaderVariantCollector.EditorUpdate` 中先保存集合，再进 `CreateManifest`。原第 252 行使用 `File.WriteAllText` 打开已有 JSON，目标仍有内存映射时，Unity Mono 报 `IOException: Win32 IO returned 1224`，HRESULT 为 `0x800704C8`。旧 JSON 为 76,399 字节，记录 87 个着色器、240 个变体。集合的 YAML 已有 105 个着色器引用、257 个变体条目。

第一轮只对映射占用释放 Unity 缓存句柄并异步等待。短时占用测试通过，正式 JSON 两秒后仍不能截断。Windows Restart Manager 未返回持有者；对可查询进程的映射检查未命中目标，仍有进程不可查询。真实文件允许打开删除访问权。同盘实验分别覆盖共享删除、拒绝共享删除及关闭文件句柄后存留的映射，确认共享删除的映射允许替换目录项，同时拒绝原地截断。

最终临时文件位于项目同卷 `_temp/YooAssetShaderManifests/`。先写完整 JSON，目标存在时调用 `File.Replace`，首次生成时调用 `File.Move`。仅在 Windows 错误 32 或 1224 时释放 Unity 缓存句柄并异步等待，最多十次、每次 200 毫秒。失败保留原始异常及旧 JSON，本次使用的临时文件由写入方法清理。收集器在保存前解除本轮编辑器更新回调，完成后恢复收集状态，写入成功才通知调用方。
