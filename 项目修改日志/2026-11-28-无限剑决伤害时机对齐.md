# 无限剑决（10070）伤害时机与剑落地对齐

日期：2026-11-28
涉及端：服务端结算时机 + 客户端特效时间轴
前置：上一轮修复（`ROWeaponHitSkill` 无瞄准点落点收回自身）已让空放大剑能造成伤害，本轮只处理**时机**问题。

## 现象

用户反馈：伤害算得太快，剑还没落地伤害就出来了。

## 排查结论

### 服务端原本的结算时刻

- `SkillEffectInfo` 表 10070 全部 170 级：`ImpactDelayMs = 134`、`HitCount = 2`、`HitIntervalMs = 300`。
- `ROWeaponHitSkill.Update` 以 `nextHitMs_ = ImpactDelayMs` 起算，两段伤害分别落在 **0.134s / 0.434s**。
- 逻辑帧 50ms：实际触发在第 3 帧（150ms）与第 9 帧（450ms）。

### 客户端大剑真正落地的时刻

表现资产 `SkillRuntimePresentation_3007001.asset`：

| 项 | 值 | 绝对时刻 |
| --- | --- | --- |
| 动画 `Anim_MJS_Skill04` | 1.133s | — |
| FxEvent[0] 起手粒子（Frame 4） | 0.133s | 0.133s |
| FxEvent[1] 大剑特效实例（Frame 13，PlacementKind=TargetTop） | 0.433s | 0.433s |
| `Sword` 粒子 `startDelay` | 1.05s | **1.483s** |
| `blast wave` / `TrailFlash` / `Audio` | 1.05s | 1.483s |
| `path` / `Sparks2` / `Distortion`·`fire`·`light` | 0.80 / 0.95 / 1.00 | 1.23 / 1.38 / 1.43s |

`Sword` 为 Mesh 粒子，`gravityModifier = 0`、速度模块全 0，即**原地生成不飞行**，因此 `startDelay` 结束时刻就是剑砸到位的时刻。

**服务端伤害比剑落地早约 1.0 秒**（0.134s vs 1.483s），第 2 段也早 1.05 秒。

### 更底层的矛盾

技能总时长由 `SkillPresentationInfo` 决定：

- `DurationMs = 1133`、`SkillStateTimeMs = 1133`。
- `ROSkillComponent.cs:970-984`：`cast_duration_ms` 优先取 `SkillStateTimeMs`，因此服务端技能实例只存活 **1133ms**。
- `ROWeaponHitSkill.Update` 首行 `if (!base.Update(delta_time)) return false;`，到期即停止结算。

即：**整组打击特效的爆发（1.38–1.48s）发生在技能结束之后**，特效设计与技能时长本身就不匹配。若只把 `ImpactDelayMs` 改大，伤害会因技能到期而永远不结算。

## 未采用的方案

**延长技能时长到 1.633s（Timeline 长度）**：需同时改 `SkillPresentationInfo` 与 `SkillRuntimePresentation_3007001.asset` 的 `DurationSeconds`。`MArtSkill.cs:222-234` 对两者差值有硬校验，偏差超过 0.05 秒会直接 `LogError` 并**停止派发全部表现**；且动画本体只有 1.133s，尾部会定格。改动面大、回归风险高，本轮不采用。

另注：`tbskillpresentationinfo.bytes` 的 xlsx 与线上数据存在 2 字节既有差异（500 → 700，非本次产生），本轮刻意不触碰该表。

### 1. 客户端特效 `Effect_Skill04.prefab`

把 12 个子效果的 `startDelay` 统一减 0.55 秒，使整组打击效果落进技能时长内：

| 子效果 | 原 delay | 新 delay | 新绝对时刻 |
| --- | --- | --- | --- |
| Effect_Skill04（根） | 0.25 | 0 | 0.433s |
| ImpactLightnings | 0 | 0 | 0.433s |
| path | 0.80 | 0.25 | 0.683s |
| Sparks2 | 0.95 | 0.40 | 0.833s |
| Distortion / fire / light | 1.00 | 0.45 | 0.883s |
| **Sword** / TrailFlash / Audio / blast wave / 子效果 | 1.05 | **0.50** | **0.933s** |
| plan | 1.10 | 0.55 | 0.983s |

该 prefab 仅被 `Jx_Skill04.asset`、`SkillConfigSO_3007001.asset`、`SkillRuntimePresentation_3007001.asset` 引用，均属 10070，不影响其他技能。

- `ImpactDelayMs`：134 → **930**（对齐剑到位的 0.933s）
