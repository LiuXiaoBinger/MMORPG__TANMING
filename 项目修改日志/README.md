# 项目修改日志

本目录是项目修改说明的唯一归档位置。代码、配置、协议、数据表、资源、场景、工具或文档发生修改后，都应在这里新建或追加 Markdown 记录。

每条记录至少包含修改日期、需求目标、修改文件、实现内容与设计思路、验证方式和结果、未解决问题及后续交接。文件名优先使用 `YYYY-MM-DD-主题_CHANGELOG.md`；同一功能连续返工时更新原记录，避免重复散落。

每次代码交付必须逐项列出新增、修改、移动、删除的文件及用途和具体变化，Unity `.meta` 可与对应文件合并说明；同时记录功能分支、提交范围、验证结果与推送状态。提交消息使用中文正文引用本目录对应日志，最终回复附文件清单、提交号及上传结果。当前开发分支为 `codex/feature-development`，只有用户明确要求时才合入主分支。

`Docs/AI/CURRENT_TASK.md` 和 `TEST_REPORT.md` 仍用于当前协作状态与测试流水，不替代本目录的项目修改说明。
