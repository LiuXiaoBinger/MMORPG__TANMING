# 一区 RO 进图选线、按人数扩线与双城传送

任务编号 `REALM-RO-ENTRY-PORTALS-20261126`。Codex 实现并用本机隔离一区验收。参考 RO 的 `SelectPrioritySceneLine`、`SelectSceneStrategyRoleNum`、`UpdateSceneNum` 和 `CGsManager::GetGsLine`。已有城际传送门、两张地图的出生位置与手动选线入口继续使用。

## 配置与行为

- 一区的主城为地图 0，天空中之城为地图 1。每图常驻 1、2 线，分别由 GS1、GS2 承载。人数警戒为 400，容量阈值为 500，本次设置的每图总线数上限为 8。两张地图的阈值和总线数可以分别在 `LYF_Server/区服部署/配置/1区.xml` 修改。
- 初次登录选存档地图，按线号取第一条低于警戒的线。传送门优先在目的城找原 GS 能再容纳一人的线，再用普通选线。普通回退沿用 RO：所有线达到警戒时取占用最少者，即使该候选已达到容量阈值。手动指定线、组队指定宿主和传送的原 GS 优先路径都会检查容量。
- 选线占用包含正在交接的人数，目录人口与扩线依据只计已确认进入的人。每图同一时刻只申请一个实例。GS 建立独立视野名单并回包后，玩家才可以进入。闲置弹性线回收后，其线号可重用，新实例取得新 UID。门的目的地、门圈和楼层继续由服务端检查。
- 区级 `chooseGsType="1"` 在已注册 GS 间按编号轮询，两座城共用游标。`2` 使用负载评分。CPU 低于 60% 的节点优先，全部达到警戒时取其中最低分。整数 CPU 百分比、公共城实例、其他公共野外实例、活跃副本的权重分别为 30、10、20、40。GS 在评分模式下每五秒上报一次进程 CPU 和副本数。小地图每次展开都查询本角色所在地图的当前目录。

## 验收

| 条件 | 结果与证据 |
|---|---|
| 旧控制服，测试警戒 2、容量 3 | 复现 1 线到 3 人仍未分流、仅占位就出现新线、取消后消失、GS2 跨图被送往 GS1。见 `_temp/ro-city-routing-20261126/old-check.log`。 |
| 默认轮询，一区、双 GS、独立 MySQL、九个角色 | 登录在各线到警戒时分流。天空中之城 3 线分给 GS1（UID 5），主城 3 线分给 GS2（UID 6），回收后天空中之城 3 线再次创建为 UID 7。门外与错误楼层被拒绝，手动切入满线被拒绝。降低阈值的副本位于隔离目录。见 `_temp/ro-city-routing-20261126/workspace-round-robin.log`。 |
| 评分模式，双真实 GS | 两个进程都发出 CPU 报告，完成两图扩线与门间往返。另用四组受控节点输入驱动真实 ControlServer，验证 CPU 警戒分组、全高负载回退、场景权重、预留和取消、建图回执、总线数上限。见 `_temp/ro-city-routing-20261126/workspace-score.log` 和 `_temp/ro-city-routing-20261126/contract.log`。 |
| Unity Play Mode 连隔离一区 | 实际 TCP/KCP 握手后，测试主角沿两城烘焙导航面移动。正式 `CheckCityPortal` 触发两次申请。天空中之城 → 主城 3 线 GS2，展开菜单后显示三条线路，再从主城 → 天空中之城 2 线 GS2。使用验证场景副本、自动移动和 Editor 场景加载。见 `_temp/ro-city-routing-20261126/candidate-unity-run1/Unity.log`。 |
| 编译与范围 | 工作区客户端和 Game、Control、Gate、Center、Master、Login 六个服务工程均通过。干净分支上的六个服务工程也通过。独立客户端候选与原基线均出现同一个 `MainCtrl.cs` 的 CS0246，缺少未纳入该分支的 `CurrencyExchangeCtrl`。见 `_temp/ro-city-routing-20261126/branch-check.json`。 |

Unity 验证脚本首次编译误将角色编号当成无符号实体配置参数，改用项目的实体创建参数后完成往返。旧服对照脚本首次生成的测试 XML 编码名不能被 .NET 识别，改为 UTF-8 后完成旧行为复现。这两处调整都在隔离验证工具中。

实际网络试验只启动隔离一区，警戒与容量降为 2/3，常规试验的总线数上限为 4。未做每线 400 人实压、真机、独立 Player 或跨机器演练，当前正在运行的开发服未重启。本地证据及用量摘要位于 `_temp/ro-city-routing-20261126/`。
