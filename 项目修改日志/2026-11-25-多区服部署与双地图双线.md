# RO 式多区服部署与单区双图双线

任务编号 `REALM-DEPLOY-TWO-MAPS-20261125`。开发由 Codex 执行，记录子 Agent 同步并核对本次新增的中英文索引。分支 `codex/feature-development`。

## 部署与设计

共享 LoginServer 和 CenterServer，每个区使用独立的 GateServer、ControlServer、MasterServer 以及两台 GameServer。首次在项目根目录运行 `& '.\LYF_Server\区服部署\启动区服.ps1' -IncludeShared` 即可启动一区。区服 XML 指定物理节点与端口，公共服务 XML 指定共享端点和区服文件列表。二区的编号与端口已另行分配。启动与停止命令见 `项目分析/同区多GS与地图分线.md`。

一区当前使用项目内的地图 1 和 0，各设 1、2 线，每线配置容纳 500 人，固定落在 GS 1 和 GS 2 上。每张地图的两条线独立计算视野、附近聊天和人数。准备好新地图后，可在区服文件中修改四条 `scene.map`，同步设置 `spawnMap` 和客户端地图路由。配置于进程启动时加载，已有角色保留存档地图。

中心服仅向客户端返回 XML 清单中已经登记为在线的区服，网关提供区号，公网地址与名称取自本地配置。账号、区服号、角色存档和已有数据库结构沿用；旧展示记录可原样保留。停/开区后的选择依据和复现过程见 `项目分析/项目难点.md` 同编号段。

- 两次验收分别以 1、0 作为测试配置的出生地图。为准备两张地图的六人阵容，测试夹具预置部分角色的持久地图。额外建角验收通过真实建角协议直接进入地图 0 的 1 线并切到 2 线，数据库记录为 0，原地图 1 角色的记录仍为 1。
