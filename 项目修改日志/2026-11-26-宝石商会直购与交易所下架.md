# 宝石商会直购、强化石下架与魔剑士升级材料

任务编号 `GEM-CHAMBER-MARKET-20261126`，功能分支 `codex/feature-development`。开发者选择由 Codex 执行业务修改，并批准将本次新增协作记录交子 Agent 做双语同步。

## 玩家可见的变化

- 交易所移除全部 23 种镶嵌宝石的 1～10 级，以及 1～5 级强化石。宝石包括月光石、天河石、青金石、寿山石、孔雀石、紫牙玉、梅花玉、血玉，以及蓝、黑、红、绿、黄五色的水晶、玛瑙、琉璃。商会按 1、2、3 级各售 23 种，单价依次为 60,000、120,000、240,000 铜钱，每个商品与工坊共用 900 件配额。不同等级和品种各自结算。
- 旧寄存物留在卖家的「出售」页，可取回余货、领取已售货款。公开目录、报价、购买和重新上架均按物品编号应用新规则。
- 「摆摊 → 购买 → 装备升级 → 魔剑士材料」展示锤锻和冶铸两套图样。每套依次为武器、发冠、上衣、下装、鞋履、腰带、护腕、戒指、项链、玉佩。锤锻的使用等级为 90 级，说明对应 80～120 级升级。冶铸的使用等级为 130 级，说明对应 120～160 级升级。
- 商品卡以当前市场的在售余量决定去向。无货时直接显示该物品简介，有货时进入卖家挂单。若打开第一批挂单前已经售罄，回到刚才的分类并显示简介。材料简介可展开「摆摊购买」「副本商店兑换」两种获取途径。此处实现了参考图的物品信息展示，本次验收未涉及实际副本兑换或装备升级消耗。
- 23 种宝石使用 RO 物品插画与游戏品质框，115 个图集切片覆盖不同档位。锤锻与冶铸分别采用新绘制的展开卷轴与竹简，20 个图标用「魔」字和部位角标区分。图样颜色、边框和弹层沿用本项目交易界面。

## 验收与证据

证据根目录为 `_temp/gem-chamber-20261126/`。

- `server-checks.log` 中 31 项检查通过。覆盖 69 个商品的双件购买、旧客户端按一件购买、余额不足、配额不足、背包容量不足整单不扣款、满堆可接收、合成、禁交易旧单回收与提款。20 件升级材料逐个通过中心服上架准备并能从交易服取得对应挂单。

## 追加的装备特技盾形铁牌

开发者明确指定铁牌采用盾形、升级等级共用图标。特技配置共有 300 条等级记录，其中 98 条为各族的一级记录，另外 202 条为升级记录。每种基础特技对应一个物品。原有六种保留编号和摆放顺序，补入 92 个物品；两个品质的同名减抗特技本来就是独立配置，保留各自品质和铁牌。摆摊中的 98 种归入既有「特技谱」一栏，其他市场沿用原有陈列范围。

所有铁牌使用金属盾面、铆钉与彩色浮雕。「神力·外」为拳甲，「神力·内」为气旋，「妙手」为托珠双掌，「虚弱」为锁链裂盾。整图的 98 个切片逐一绑定对应的物品编号，品质底框使用本项目同风格的物品框。
